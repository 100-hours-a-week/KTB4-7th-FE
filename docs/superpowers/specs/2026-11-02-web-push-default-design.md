# 웹푸시 기본 사용 설계

- 목적: 알림 종류별 설정은 유지하고 브라우저 푸시 전용 설정 행 전체를 제거한다.
- 접근: 알림 설정 화면에서 권한이 아직 결정되지 않았으면 브라우저 권한을 요청한다. 허용된 브라우저에서는 페이지 진입과 로그인 후 FCM 토큰을 서버에 자동 등록한다.
- 제약: 브라우저가 권한 요청을 차단하거나 사용자가 거부하면 푸시 수신을 강제할 수 없다. 로그인하지 않은 상태에는 토큰을 서버에 등록하지 않는다.
- 오류: 토큰 등록 API 실패와 브라우저 권한 문제를 구분해 표시한다. DevTools 응답 본문 부재만으로 서버 오류 원인을 단정하지 않는다.
- 범위: 기존 `/v3/notifications/fcm-tokens` API와 알림 종류별 설정을 유지한다.
